# PetReminder para Android

Repositorio de distribución de la aplicación. El código fuente se mantiene en [Eieen56/pet](https://github.com/Eieen56/pet).

La beta `1.0.0-beta.1+2` está en preparación. El APK, los requisitos confirmados, las notas y el archivo SHA-256 se publicarán en [Releases](https://github.com/Eieen56/app_pet/releases) después de verificar la compilación. No hay instalador entregado hasta que aparezca una Release preliminar con su APK.

[Guía de pruebas beta](https://github.com/Eieen56/pet/blob/main/docs/PRUEBAS_BETA.md). Los tres testers deben usar el mismo archivo y comprobar su hash.
